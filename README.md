# HR Analytics Dashboard (Excel Project)

## 📊 Project Overview
In this project, I analyzed HR data using Excel, Power Query, Pivot Tables, and an interactive dashboard to identify key business insights related to salary structure and employee performance across different departments.

---

## 🧹 Data Cleaning & Preparation
- Cleaned and transformed raw data using Power Query
- Handled missing values and structured the dataset for analysis
- Prepared data for visualization and KPI creation

---

## 📈 Analysis & Dashboard
Built an interactive Excel dashboard including key KPIs:

- Total salaries
- Number of employees
- Age distribution
- Average working hours

---

## 🔍 Key Insights
- Employee distribution across regions
- Average working hours by department
- Gender ratio (Male vs Female)
- Performance comparison across departments
- Salary gap analysis (expected vs actual salary)
- Age group analysis and its relation to performance

---

## 🎛️ Interactive Features
- Department filter (Slicer)
- Manager / Non-Manager filter
- Age group segmentation filter
